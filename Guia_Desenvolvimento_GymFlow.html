2 Modelo de Versionamento: GitFlow

Para garantir a colaboração eficiente sem conflitos, o time adota o GitFlow estruturado com as 4 branches oficiais:

main ───●───────────────────────────────────────────────────────●─── (Release v1.0) \ / develop ────●────────●─────────────●─────────────●──────────────●───── (Integração) \ \ \ \ / feature/login └──●─────┘ (Gustavo: Login/Home) \ / feature/workout-builder ──────────────────└──●──────────┘ (Ícaro: Wizard)/ feature/exercises ─────────────────────────────└──●──────┘ (Guilherme)/ feature/workout-tracker ───────────────────────────────────────└──● (Jeann)
Responsabilidade por Domínio: Cada membro é proprietário de suas respectivas telas e hooks em diretórios isolados, evitando sobreposição e garantindo autonomia durante o desenvolvimento.

3 Divisão Oficial de Tarefas da Equipe

👤 Gustavo (2 Telas) feature/login

Módulo: Autenticação, Sessão & Dashboard Principal

  • Telas: Splash / Onboarding (Figma 1) + Dashboard Principal (Figma 2).
  • Autenticação: Login, cadastro, recuperação e modo visitante (Guest Mode).
  • Dashboard: Header com avatar do usuário, 3 KPI Cards com métricas do dia, lista de treinos recentes e atalhos rápidos.
  • Navegação: Configuração base da **Bottom Tab Bar** (5 abas: Início, Alunos, Exercícios, Treinos, Mais).
  • Persistência: Armazenamento local do token de sessão no AsyncStorage.
Supabase Auth AsyncStorage Bottom Tabs StatCards
👤 Ícaro (3 Telas / 1 Fluxo) feature/workout-builder

Módulo: Criador de Treinos (Wizard em 3 Etapas)

  • Telas: Seleção de Aluno (Figma 5) + Adicionar Exercícios (Figma 6) + Configuração de Séries (Figma 7).
  • Stepper: Componente visual numerado de 4 etapas no topo.
  • Seleção Múltipla: Listagem com checkboxes dinâmicos e botão inferior com contador (*"Adicionar selecionados (2)"*).
  • Configuração Fina: Ajuste de séries, repetições, carga (kg) e descanso (s) por exercício, salvando o treino montado no Supabase.
  • Persistência: Rascunho da montagem do treino no AsyncStorage.
CRUD Treinos Stepper Wizard useWorkoutBuilder Checkboxes
👤 Guilherme (2 Telas) feature/exercises

Módulo: Catálogo & Cadastro de Exercícios

  • Telas: Catálogo de Exercícios (Figma 3) + Novo Exercício (Figma 4).
  • Filtros & Busca: Pesquisa textual com hook de debounce e chips de grupo muscular (Peito, Costas, etc.).
  • Formulário: Cadastro com validação de campos obrigatórios e instruções.
  • Hardware / Câmera: Integração com expo-image-picker para foto do exercício.
  • Persistência: Cache offline de exercícios favoritados no AsyncStorage.
CRUD Exercícios expo-image-picker useDebounce FlatList
👤 Jeann (2 Telas) feature/workout-tracker

Módulo: Execução ao Vivo, Notificações & Progresso

  • Telas: Acompanhamento ao Vivo (Figma 8) + Progresso e PRs (Figma 9).
  • Execução: Check de séries, barra de progresso visual e cronômetro de descanso (60s/90s).
  • Notificações: Disparo via expo-notifications ao término do descanso em background e lembretes diários.
  • Métricas: Gráficos de evolução de carga temporal e recordes pessoais (PRs).
  • Persistência: Estado do treino ativo salvo no AsyncStorage caso o app feche.
expo-notifications Gifted Charts useRestTimer ProgressBar

4 Matriz de Cobertura de Requisitos de React Native

Persistência de Dados Sessão de usuário, rascunho de treino, cache offline e treino em andamento @react-native-async-storage/async-storage Toda a Equipe
Requisição Web Services Autenticação, busca de KPIs, CRUD de treinos, exercícios e conclusão de sessões @supabase/supabase-js (REST API) Toda a Equipe

6 Guia Prático de Comandos Git para a Equipe

1. Inicializando uma Nova Branch de Trabalho

# Sempre parta da develop atualizada:
git checkout develop
git pull origin develop

# Crie e publique sua branch (exemplo para o Ícaro):
git checkout -b feature/workout-builder
git push -u origin feature/workout-builder

2. Rotina de Commits Diários

git add .
git commit -m "feat(builder): implementa selecao de aluno com radio button"
git push

3. Finalizando a Tarefa e Abrindo Pull Request

# 1. Sincronize com a develop antes de abrir o PR para garantir que não há conflitos:
git checkout develop
git pull origin develop
git checkout feature/workout-builder
git merge develop

# 2. Se tudo estiver ok, envie ao GitHub e abra o Pull Request para a branch 'develop':
git push origin feature/workout-builder
